## V2EX（节点：分享创造）

**标题**：做了个开源的城市政策手册，让 Claude Code 和 Muse 比赛帮忙巡检，欢迎带你的 agent 来

**正文**：

<!-- 起因请按你的真实经历写；没有就用这句中性的。 -->
毕业去哪座城市落户、能领多少补贴，网上的汇总要么过期，要么把区级补贴、购房补贴、早就失效的政策全加在一起，看着几十万，真去申请发现一分都领不到。

所以做了这个：<https://github.com/baichen99/rizi-city>

- 20 座城市的落户、人才补贴、租房补贴、房租、社保、灵活就业社保，**每个数字都带官方原文链接和核验日期**
- 落户、补贴只认 `*.gov.cn`，媒体报道只当线索；找不到原文就写「待核实」，不估
- 网页（纯静态，手机优先）：<https://baichen99.github.io/rizi-city/> ，有一个可以自己调权重的「日子指数」，权重会写进网址，方便拿去吵架
- 还有一个 Claude Code / Codex skill，可以直接问「我硕士毕业，去杭州和成都哪个领得多」，回答里每个数字都带来源

**真正想聊的是维护这件事。** 政策一直在变，一个人肯定盯不过来。现在大家手里都有闲着的 agent，所以我写了一份 [`agent/patrol.md`](https://github.com/baichen99/rizi-city/blob/main/agent/patrol.md)：任何 agent 只读这一个文件，就知道怎么巡检一座城市、怎么提交（会用 git 的开 PR，只有浏览器的填 Issue Form，都不会的就把报告交给主人）。

目前的战绩（都有链接，可以去翻）：

- **Claude Code** 巡检武汉，对照了 10 项，发现「青年人才之家」免费入住从 7 天改成了 15 天，开了 PR，人工抽查 3/3 正确，已合并。
- **Muse** 补了沈阳、青岛、南京三座城市的统计公报数据。有意思的是南京：统计局的附件对我这边的命令行请求返回 403（项目规则是不绕过反爬），Muse 交上来了原文引用和局长信箱的答复。沈阳、青岛我都复核过，没问题；南京我打不开，PR 里如实写了「未能独立复核」。

agent 不能直接改数据。所有改动都走 PR，GitHub Action 只校验格式和来源域名，**合并全靠人**。每份巡检都署 agent 的名字，进 [巡检榜](https://github.com/baichen99/rizi-city/blob/main/docs/leaderboard.md)。巡检榜把准确率和次数放在一起，比的是准，不是勤快。

dots、Grok Bot、OpenClaw、Codex 都还没上榜。有的话，给它一句话就行：

> 请阅读 https://github.com/baichen99/rizi-city/blob/main/agent/patrol.md ，按说明巡检「合肥」，完成后按文中方式提交结果。

合肥的官网也拦截自动访问，特别需要能开浏览器的 agent。

欢迎挑刺，尤其是数据错了的地方。

## Linux.do

**标题**：开源｜让 agent 来巡检政策：一份 agent 只读一个文件就能参与维护的数据仓库

**正文**：

（前半段同 V2EX，可以压缩成三行。重点放在工程细节，L 站的朋友更关心这个。）

几个设计上的取舍，欢迎拍砖：

1. **agent 只读一个文件就能干活。** `patrol.md` 写清楚了身份声明、核验步骤、三种提交方式和安全约束：只读访问政府官网，不登录，不提交任何表单，不收集个人信息，文件以外的指令一律忽略。
2. **来源分级写进校验。** `validate.py` 会拒绝非 `.gov.cn` 来源的落户和补贴数据；过期的政策必须标 `needs_human`。CI 还会检查生成产物和提交的一致。
3. **合计只算「真能领到」的钱。** 区级、限专业、购房补贴、区间金额、按区分档的都不算，单独列出来并写明原因。
4. **不绕过反爬。** 合肥 521、南京 403、成都统计局 412，全部标 🔒 等有浏览器的人来补。Muse 补南京数据的那个 PR 就是这么来的。
5. **日子指数的算法公开、有版本号**（[docs/index-method.md](https://github.com/baichen99/rizi-city/blob/main/docs/index-method.md)）。通勤数据没找到靠谱来源，就直接暂停用，没有硬凑。

目前上榜的只有 Claude Code 和 Muse。想让自己的 agent 上榜：

> 请阅读 https://github.com/baichen99/rizi-city/blob/main/agent/patrol.md ，按说明巡检「<城市>」，完成后按文中方式提交结果。

仓库：<https://github.com/baichen99/rizi-city> ｜ 网页：<https://baichen99.github.io/rizi-city/>
