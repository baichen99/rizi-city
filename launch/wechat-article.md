毕业去哪座城市，落户方便吗，能领多少补贴？网上的汇总看起来都很丰盛，动不动「本科补贴 X 万」。真一条条去找原文，问题就出来了：有的是区里发的，只有在那个区工作才有；有的限专业；有的要买房才能领；有的文件三年前就到期了；还有的所谓「补贴」，其实是住进指定的人才公寓才打折，一分现金都没有。

这件事值得认真做一遍，而且要做成大家都能接着维护的样子。于是有了「日子人城市指南」。

### 三条规矩

**第一，不编数字。** 找不到原文的写「待核实」，有歧义的写清楚卡在哪，不估、不猜、不用「约」糊过去。

**第二，只认官方原文。** 落户和补贴只认政府官网（`.gov.cn`），媒体报道只当线索。房租用权威监测机构的数据，收入和消费用各市统计公报，都写明年份和口径。

**第三，政策有有效期。** 文件写了有效期的都记下来，过期就标出来，再去找接替文件。比如杭州 2023—2025 年的应届生补贴计划已经到期，在找到新文件之前，它的补贴不算进合计。

所以你在网页上看到的每个数字，点开都能看到原文链接和最近一次核验的日期。

### 能用它查什么

网页手机就能打开：baichen99.github.io/rizi-city（小程序和公众号里点不了外链的话，复制到浏览器）。

**🎓 我是应届生**：选学历，看每座城市能不能落户、能领多少。

「能领多少」只算市级、面向普通应届生、有官方原文、没过期的现金补贴，按原文上限加起来。按这个口径，本科能领最多的是宁波（3 万，租房补贴每年 1 万、最长 3 年），然后是济南、苏州、青岛、长沙。

很多城市显示 0，这不是没查，是查过了确实没有市级现金补贴，网页上会标「✅ 已核实：无市级现金补贴」。查过但没算进去的，比如已到期的、按区分档的，会单独列出来，写明原因。

**📝 我在考公考编**：一个应届身份自查工具。国考报考指南的原文是：离校时和两年择业期内**未落实工作单位**，户口、档案、组织关系还在学校或人才服务机构的，可以按应届生对待。

很多人关心缴过社保还算不算。**原文没有提社保。** 所以工具在这种情况下会告诉你「说不准，以招考公告为准」，不替你下结论。

**💻 我是自由职业**：自己交社保，每月最少多少？按灵活就业最低档算，目前能算清楚的 7 座城市里，重庆最少（约 1169 元/月），上海最多（约 2641 元/月）。北京的灵活就业参保限本市户籍，这一点不查原文很容易忽略。

**🏆 日子指数**：下面单独说。

### 日子指数：不是给城市打分，是帮你想清楚自己在乎什么

日子指数用五项公开数据：房租负担、生活成本、落户难度、补贴力度、社保负担。每项归一化到 0—100 分，再按权重加权。

等权重下，前五名是苏州、长沙、宁波、杭州、西安。但这个排名本身没太大意义，因为每个人在乎的东西不一样。所以权重可以自己拖：更在乎房租的，把房租调到 3 倍，长沙就排到了第一。调好的权重会写进网址，可以发给朋友，看看谁的活法更合理。

还有几点要说清楚：

- 缺 2 项及以上已核实数据的城市不参与排名，单独列在「数据收集中」。宁可少排几座，也不硬凑。
- 通勤本来也是一项，但没找到口径统一、能看到发布方原文的数据，就先停用了。
- 算法、公式、版本号都公开在仓库里。**日子指数只反映公开数据，不代表城市好坏。** 觉得权重不合理，欢迎来提 Issue 吵。

### 谁来维护：你的 agent

政策一直在变，一个人盯不过来。

现在很多人手里都有闲着的 AI agent，所以我写了一份巡检说明。任何能浏览网页的 agent，读这一个文件就知道怎么对照官网核对一座城市，核对完再按自己的能力提交：会用 git 的开 PR，只有浏览器的填 Issue，都不会的就把报告交给主人。

它们只能读政府官网，不登录、不提交表单、不碰个人信息。所有改动都要人来审、人来合并。

到目前为止：

- Claude Code 巡检武汉，发现「青年人才之家」的免费入住从最长 7 天改成了 15 天；
- Muse 补齐了沈阳、青岛、南京的统计公报数据。

每份巡检都会署上 agent 的名字，进巡检榜。巡检榜同时展示次数和抽查准确率，比的是谁更准，不只是谁更勤快。

### 几个不知道就吃亏的坑

1. 应届生身份看的是「有没有落实工作单位」，不只是毕业几年。
2. 上海应届生落户：在校期间缴过社保、走中介派遣入职的，不受理。
3. 补贴大多有申请时限，过期不补。
4. 「能落户」和「能领钱」是两套条件。比如青岛的住房补贴要求申领时已经是青岛户籍。
5. 很多「补贴」其实是指定房源的租金折扣，不是现金。
6. 政策有有效期。苏州、广州现行的落户办法 2026 年底到期，成都的 2027 年 2 月到期。
