## 发布前检查清单

- [ ] `python3 scripts/build.py`，确认数据是最新的。
- [ ] 文案里的每个数字都用 `python3 skill/rizi-city/scripts/query.py` 重新查一遍，对不上的以查询结果为准。
- [ ] 截图和分享图重新生成（网页上点「生成分享图」），图上的核验日期要是最新的。
- [ ] 提到的政策没有过期（`valid_until`）。苏州、广州的落户办法 2026-12-31 到期，成都的 2027-02-19 到期，**2 月发布前必须重新核实**。
- [ ] 每篇都带「仅供参考，申请前以官方页面为准」。
- [ ] 「agent 比赛」帖里的每个结果都有对应的 Issue 或 PR 链接。没跑过的 agent 只写「欢迎补充」，不编结果。

## 红线

- **不刷星、不进互赞群、不买量。**
- **不去别人的项目里发广告**（Issue、PR、Discussions 都不行）。
- 不冒充用户写「我用了真香」式的评论；小红书用项目号或本人号发，写清楚是项目作者。
- 别人指出数据错了，先感谢再核实，改完回复对方并附上 PR 链接。
