# 月消费参照与个人预算

本页将“居民统计消费水平”和“用户自己的现金预算”分开，均不加入日子指数，不改变其五项原指标、权重或归一化公式。

## 先看月消费量级

只采用通过居民统计元数据门禁的平均消费：原年值÷12，卡片取整到百元。卡片直接标明资料年份、常住人口范围及初步数，说明这是统计平均，不是每个人的实际账单。原年值、精确到元的月均换算及来源折叠保留。年数摊到12个月不构成新的月度观测。

比较只包括同年、同人口类型、同地域类型、同方法、同名义金额口径、具有合法固定跨城键且未过复核期的城市。按未舍入的年值排序，相等值并列；明说当前可比城市数，不冒充全国排名。只有一城时不给相对名次。旧记录缺元数据时不赋予比较等级。消费排名不是物价、负担或幸福排名。

同范围居民人均可支配收入可并列显示，不能称为工资。单位就业人员平均工资、工资中位数仍是独立指标；缺中位数不从均值推算。更完整的口径见 [居民统计元数据](resident-statistics-metadata.md)。

## 再算自己的预算

用户选“直接填整户月总额”或“按项目拆开算”，两者互斥，绝不相加。项目均为整户现金金额，不再乘人数；人数只用于展示简单人均分摊。计划支出覆盖住房、吃饭、水电气、全年供暖、交通、另付税费社保及其他。用户应把债务、医疗、育儿等也放入适当项目。储蓄独立填写，不混在开销内重复扣除。

- 整户可用收入指已扣税、代扣社保和公积金后的金额；只有尚未扣缴的税费或自缴社保另计。
- 水电气等可以标为已含在指定承接项目。承接项目必须单独填写有效金额，不能循环、串联包含或只留空。明确“不适用”可以排除；未填项目是未知，不按0。
- 单独缴纳的全年供暖费除12用于月预算，实际账单支付月份可能集中。空调取暖已含电费时不重复相加。
- 金额接受0至1000万元且最多两位小数，人数为1至30的整数；空白、非法数字编辑态、负数、非有限值或超限均不能生成完整结余结论。
- 缺项只显示“已填合计，还没算……”；齐全后才显示“整户计划月开支”。收入未填不默认0；储蓄目标未填不等于用户确认目标为0。
- 有收入后给出“还能留X元／还差X元”；有储蓄目标后说明目标后的余量或缺口。仅实际差额为0才说“刚好”，不用任意比例阈值判定幸福、宽裕或贫困。

所有输入仅在当前页面内存保留，按城市隔离；刷新即清空，可手动清空。不写入浏览器持久存储、URL、分享图或网络请求。不自动读账单，不收集身份信息。

## 绝不重复相加

官方居民消费已含居住、水电等类别，还可能包括自有住房虚拟租金等非现金消费，不能再加房租、水电或个人预算。个人现金预算也不能据此直接判为高于平均就“花太多”。现有水电气模块仍是来源导航，没有启用真实费率或虚构“平均账单”。自动计费需另行补齐供区、现行费率、阶梯周期等证据，见 [生活模块方法](life-modules-method.md)。

## 验证

`node --test tests/living-budget.test.js` 覆盖双模式、人数、包费承接、年度分摊、缺项、非法数值、收入和储蓄目标、微小缺口、同口径参照及隐私边界。浏览器回归覆盖6种宽度，包含输入不完整数字、模式切换、明细包费、刷新与清空，以及暗色显示。
