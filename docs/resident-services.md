# 本城居民查政策与办事入口

## 页面与需求

选择城市后，在日常生活内容之后提供“在本城，你想查什么”。生活内容优先，不把查政策入口放在日常生活之前。入口按补贴救助、住房落户、看病医保、就业社保、水电气暖、生育入学、养老退休七类需求组织，不要求居民先理解数据字段。

- 复用城市 YAML 的落户、补贴、灵活就业资料及已有生活导航，不修改城市政策事实、金额或指数。
- 所有补贴仍归补贴主题；住房导航另识别租房/购房类型及明确的住房名称词（租房、租金、住房、租赁、安居、住宿、购房、驿站、一张床），包括非现金住宿与租金减免。此分类只用于查找，不改变现金合计或资格判断。新增名称不含这些词时应补分类回归测试。
- 本城资料与全国官方导航分组。未覆盖的低保救助、育儿入学、地方养老待遇等显示缺口，不把人才政策当作所有居民政策，不把全国目录当本地已核实规则。
- 关键词仅在当前主题、当前城市及全国导航的已收录文字中检索，不调用搜索接口。切换主题或城市清空关键词；刷新和历史链接不保留它。关键词不进 URL、localStorage 或分享图片。年龄、家庭情况、身份证等不收集。

## 证据与时间

每条线索保留适用对象/范围、资料期间、有效截止日、申请窗口（如有）、原文发布日期、核验日及来源链接。各日期含义分开，复核日不是政策截止日。

- 已过期文件显示“仅历史线索”；未来生效、格式错误、异常核验日、未核实或访问受限的来源不能显示为可申请政策。
- 没有明确有效期写“有效期待确认”，不能把空值解释为长期有效。资料已收录也不代表资格符合、申请窗口开放或办理系统可用。
- 现有模块保留供区、险种、历史年份及未复核说明。全国目录过复核期后，在浏览当日（包括离线版）降级为待复核。
- 原文不等于申办页面。页面不代办、不登录、不上传材料、不测算医保待遇或未核实账单。

## 全国目录增量与维护

原始文件为 `data/resident-services.json`，构建后进入 `cities.json` 顶层 `resident_services`，并打包离线单文件。只有链接和项目自写短导航，不再分发来源全文或表格。

2026-11-10 打开核对四个国家政务服务平台目录：

1. 地方政府服务直通车：`https://gjzwfw.www.gov.cn/fwmh/item/ztc_index.do`，核对地区切换、地方政府服务、个人办事。页面默认地区不能代表用户所选城市，明确要求自行切换。
2. 生育服务：`https://gjzwfw.www.gov.cn/col/col1248/index.html`，核对出生登记等栏目。不同抓取快照对“新生儿出生一件事”显示不同，因此摘要不据此作稳定入口承诺。
3. 养老退休：`https://gjzwfw.www.gov.cn/col/col1558/index.html`，核对退休服务、养老机构/社区/助餐以及地方专区。
4. 医保服务：`https://gjzwfw.www.gov.cn/col/col1576/index.html`，页面标题是“2025医保服务专区”，保留这一年份，不冒充2026年度地方待遇。

四个目录经独立复核。没有登录、提交申请或实测下游服务。动态目录无统一发布日期和政策有效期，字段明确留空/说明，计划复核日为 2026-12-10。该日期是维护期限，不是自动任务或更新承诺。

`scripts/resident_services.py` 校验政府 HTTPS 域名、必需范围证据、日期顺序、需求分类和 link-only 类型。拒绝金额、资格、政策生效期限等不属于导航的字段；以后新增真实政策应使用适用的政策数据结构与核验流程。
