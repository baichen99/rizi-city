# 居民城市指南：第一阶段实施记录

- 设计依据：[方案 PR #41](https://github.com/baichen99/rizi-city/pull/41)。
- 实施日期：2026-11-09。
- 状态：第一阶段已通过[PR #43](https://github.com/baichen99/rizi-city/pull/43)合并并部署；不代表全部方案完成。
- 范围：先交付居民/比较双路径、可信概况和历史图基础、少量真实事实及官方生活资料导航。未改变旧指数、政策金额、社保底线或原数据口径。

## 已实现

### 1. 两条主路径，共用一份数据

默认入口「我住在这里」，选城后直接看事实、已有政策和官方资料。可主动在浏览器本机记住城市，随时清除；不自动定位，不注册，不保存身份、住址、个人收入或健康信息。分享URL只含公开城市ID。

「我在选城市」支持两城对照，只有指标、单位、期间、人群和明确跨城可比组相同的已核实数值进入表格。没有足够资料就说明原因，不给缺数城市更低成本或更高分。

旧 `#index`、`#grad`、`#civil`、`#free` 链接保留。日子指数仍是本科落户/补贴及灵活就业等特定视角，不升级为全体居民总分。

### 2. 概况与历史来自相同记录

新增数据在 `data/life/`，由 `build.py` 加入各城市的 `life` 对象。概况复制该指标最后一个资料期，包括该期缺失；不偷偷回退到旧期。历史图、明细表、来源、CLI、离线文件使用同份记录。

首次实施公开的新增事实为15条；后续逐城补录见 `data/life/changelog.json`。下表记录首次实施范围：

| 城市 | 指标 | 已核验资料 | 图形行为 |
|---|---|---|---|
| 北京、上海、广州 | 新建商品住宅同比价格指数 | 2026-06、07、09 | 6→7月可连线，8月未完成原文核验而留空，9月单点 |
| 广州 | 城镇非私营单位就业人员税前年平均工资 | 2023–2025 | 原文2024总体明确5人及以上，邻年未明确相同门槛，按口径分组不强行连线 |
| 广州 | 城镇私营单位就业人员税前年平均工资 | 2023–2025 | 同上 |

这不是完整房价库：价格指数不是元/㎡价格，不能倒推成交均价；绝对房价及房价中位数未收录。工资中位数没有可靠同口径原文，明确留空，不按均值系数估算。

寿命原文入口已经找到，上海年鉴与广州报告分别保留资料范围；来源使用条件、总体说明未充分确认，所以**寿命数值和寿命折线尚未公开**。北京工资、寿命也未完成核验。不能把入口卡说成已补齐统计。

原有租金、居民收入和消费仍显示原资料期及来源。旧收支字段未结构化区分城镇/全体居民，居民新视图保守说明并禁止跨城比较，不替原文虚构一个统一总体。

### 3. 图表与缺失

- 缺失、未核实、限制使用和过期数据不画成0。
- 只连接连续资料期、相同实际口径的合格点。单位、人群、地域或方法组变化拆开图，不隐藏已核实单点。
- SVG有文字说明、可键盘聚焦点和同等可读的数据表。刻度直接显示，非零起点明确提示。
- 数据构建与页面运行时都检查来源复核期限。旧离线文件不能绕过期限继续把旧数值当已核实当前资料。
- 不对工资与房价做双轴叠图，不拟合趋势、不外推未来。

### 4. 政策导航

复用既有落户、人才补贴和灵活就业记录，按事情筛选，不做自动资格判断。明确这是有限政策库，不是全体居民政策大全。

原文件和办理入口分开；未单独核实办理入口就写明。没有材料清单不补写。依据文件到期展示「延续情况待确认」，不据此断言所有待遇停止。

`subsidy_scan` 的“无”仅限原扫描范围：普通应届生市级现金生活/租房补贴，排除区级、行业限定和实物配租，不能泛化为本城没有补贴。

重新核验与政策变更分开。本阶段没有伪造「最新政策」新闻流，也没有推送订阅。

### 5. 18张生活资料导航卡

北京、上海、广州每城6张：水、电、气、供暖、气候、医保。显示具体覆盖范围、核验/复核日期、状态、限制与原因。上海/广州供暖明确未覆盖；某些价格目录仅核实到目录，不能冒充具体费率文件。

**没有开放真实账单计算。** 单独的阶梯计算函数只接受明确虚构的测试规则，覆盖周期累计、跨年拒绝、边界、舍入和失效门禁。生产模块检测到夹带费率或启用计算器会校验失败。气候没有未经授权的完整月度数据库；医保只给官方导航，不计算报销、不推断个人资格。

## 文件与命令

- `scripts/life_data.py`：来源、概况、历史模式校验与公开构建。
- `scripts/life_modules.py`：官方资料导航校验、过期降级、隔离测试的阶梯引擎。
- `data/life/sources.json`、`data/life/series/`：三城指标与来源；`data/life/changelog.json` 记录15条首次公开事实的 old/null、new 和逐项依据。
- `data/life/{utilities,climate,healthcare}/`：生活入口。
- `site/app.js`：居民、比较及旧路径；纯静态，无新增第三方JS服务。
- `query.py overview 广州`、`query.py history 广州 --metric wage_nonprivate_mean`：新CLI。
- `tests/`：Python规则/数据/旧功能回归，Node序列/路由/渲染测试。

```sh
python3 scripts/validate.py --strict
python3 scripts/build.py
python3 -m unittest discover -s tests -p 'test_*.py' -v
node --check site/app.js
node --test tests/*.test.js
bash scripts/check-no-private.sh --all
```

旧 `list / compare / rank / free / freshgrad / index` 均继续支持。提交前再次构建确认 `site/data` 与README自动区段无漂移，离线版不提交。

## 来源与审查

详见 [概况数据方法](life-data-method.md) 和 [生活模块方法](life-modules-method.md)。只收少量必要客观事实、自写说明及原文链接，不复制完整文章/表格/附件，不声称项目许可覆盖第三方原文。许可不明的来源连原始JSON都不存数值，防止只在网页遮住却从Git仓库泄露。

独立复核已确认15/15数字、15/15个生活模块独立URL和两个来源条款页。发布前补充打开[6月信息公开正文](https://www.stats.gov.cn/xxgk/sjfb/zxfb2020/202607/t20260715_1964115.html)，表1北京97.9、上海103.1、广州97.4与录入值逐项一致；原先这3项第二次复核的缺口已补齐。7月和9月正文及广州三年工资公报也已逐项复核。9月原文的2025比较基期、2026换权、市辖区和新房网签口径已获独立复核。

本次没有安排自动抓取或长期巡检，也没有扩大政府来源白名单。持续维护责任需人工认领后再扩城。

已完成的程序检查：20城严格校验、Python规则/数据/CLI测试、Node图表/路由测试、20城×4政策主题渲染、400种城市组合渲染、旧计算不受新增life层影响、旧CLI冒烟、在线JSON/离线HTML构建。渲染测试检查字符串和交互状态逻辑，不等同于真实浏览器视觉验收。

尚未完成的验收：

发布前另修复了原有“我的城市”分享图在全0权重时的空分数错误，改为提示调整权重；构建为JS/CSS引用添加内容版本并保持离线内联，减少发布后沿用旧资源的可能。第三方来源材料不受项目再许可的范围已在LICENSE与README显式说明。

以上缺口不靠估值、复制省级数字、填0或增加城市数量掩盖。PR #43在本地与GitHub检查通过、用户明确授权后合并；[Pages部署](https://github.com/baichen99/rizi-city/actions/runs/42629371817)及公网文件一致性已验证。后续数据补录继续独立评审。

## 纠错与回退

数值错误先将对应记录置null并解释；来源资格变化时改为link_only且清除原始受限值，再构建。不要仅在前端隐藏。图表方法错误可先暂停该系列展示，保留来源和缺口说明。涉及既有政策的数据修复仍走原仓库独立巡检PR。
