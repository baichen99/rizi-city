# rizi-city：日子人城市指南

用这个 skill 回答城市政策问题时，**只说数据里有的，并且每个数字都带来源链接和核验日期**。数据里没有或标了 ⚠️ 的，照实说，不要用自己的记忆补。

## 怎么查

用本 skill 目录下的脚本，只需要 Python 3 标准库：

```bash
python3 <skill 目录>/scripts/query.py <子命令> [参数]
```

脚本按顺序找数据：`--data` 参数 → 环境变量 `RIZI_DATA` → 当前目录往上的 `site/data/cities.json`（在 rizi-city 仓库里时）→ 网页版 `https://baichen99.github.io/rizi-city/data/cities.json`。输出第一行的注释会写明用的是哪份。

| 用户想知道 | 子命令 |
|---|---|
| 本城概况、工资/寿命/房价指数及来源 | `overview 广州` |
| 可得历史观测和缺失说明 | `history 广州 --metric wage_nonprivate_mean` |
| 两三座城市比一比，哪个领得多、好落户 | `compare 杭州 成都 --degree 硕士` |
| 某座城市的全部情况 | `city 武汉 --degree 本科` |
| 哪里最能领钱 / 最好落户 / 房租最低 | `rank --degree 本科 --by money\|hukou\|rent --top 10` |
| 自由职业、灵活就业自己交社保 | `free` 或 `free 武汉 北京` |
| 还算不算应届生（考公） | `freshgrad` |
| 日子指数排行、某城排第几 | `index --w 1.1.1.1.1 --city 武汉`（权重顺序：房租.生活成本.落户.补贴.社保，各 0–5） |
| 收录了哪些城市 | `list` |

学历可以写 `专科 / 本科 / 硕士 / 博士`，也可以写 `associate / bachelor / master / phd`。只有落户/应届补贴查询需要学历；`overview` 与 `history` 不要求学历，不替用户推断身份。旧学历查询用户没说学历时先问；问不了就按本科查，并在回答里说明。

## 回答规则（必须遵守）

1. **每个数字后面都附来源链接和核验日期**，直接用脚本输出里的 Markdown 链接，例如"1 万元/年（[原文](...)，核验 2026-11-09）"。
2. **⚠️ 项要单独提醒**：
   - "能领"只合计已核实、未过期的市级现金补贴，按原文上限算。
   - 脚本列出的"⚠️ 未计入"项，要告诉用户它是什么、为什么没算进去（比如政策已到期、只找到媒体线索、按区分档）。不要把它加进合计，也不要估一个数。
   - `subsidy_scan` 的无补贴仅限普通应届生市级现金生活/租房补贴，不可说成全城没有补贴，也不表示某位居民无资格。
3. **不编、不补**：数据里没有的城市或字段，就说"rizi-city 还没收录 / 还没核实"，并给出认领或提 Issue 的链接（脚本会给）。不要用训练数据里的政策印象代替。
4. **口径照原文**：年龄上限、是否要求先就业、申请时限，按脚本输出里的原文口径转述。年龄上限的"以下"含不含本数，原文没写清的，提醒用户以原文为准。
5. **有效期**：脚本标出"已过期"或数据核验已超过 90 天的，要提醒用户政策可能已更新。
6. **结尾附免责声明**：仅供参考，申请前以官方页面为准。
7. 日子指数只反映公开数据，不代表城市好坏；需要解释算法时，给出 `docs/index-method.md` 的链接。

> 用户：我硕士毕业，去杭州和成都哪个领得多？

先运行 `compare 杭州 成都 --degree 硕士`，再按下面的结构回答（数字和链接以脚本输出为准）：

- **结论一句话**：按目前已核实的数据，两座城市给硕士应届生的市级现金补贴都是 0。但原因不一样：杭州有补贴，只是政策已经到期；成都是已核实没有市级现金补贴。
- **杭州**：原来的生活补贴（硕士 3 万元）和租房补贴（每年 1 万元）都写在 2023—2025 年的文件里，已于 2025-12-31 到期，还没找到接替文件，⚠️ 所以没计入（附各自的原文链接和核验日期）。落户方面，45 周岁以下可以先落户后就业（附链接）。
- **成都**：已核实没有面向普通应届生的市级现金补贴（附依据链接）。研究生落户不限年龄、不要求先就业（附链接）。注意现行落户办法 2027-02-19 到期。
- **顺便比一下房租**：30㎡ 单间每月杭州约 1449 元，成都约 951 元（附来源）。

## 居民概况口径

工资统计是指定就业人群的年度税前均值，不等于到手工资；居民可支配收入不是工资。房价指数不是元/㎡房价。预期寿命不是个人预测；户籍与常住口径不直接排名。没有同口径中位数或历史记录就报告缺失，不估算、不补零、不沿用旧年冒充当年。日常生活入口仅导航，不能把官方资料页称作已确认的办理入口。第三方来源原文与其许可不因项目许可而改变。
